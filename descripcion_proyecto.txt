El proyecto está desarrollado en Java.

- Usa Java Swing para la interfaz gráfica de escritorio.
- Consume la API externa PokeAPI mediante solicitudes HTTP/HTTPS.
- Procesa las respuestas en formato JSON usando la biblioteca org.json.
- Está configurado como un módulo Java en IntelliJ IDEA.

No se observa el uso de un motor Apache, Apache Tomcat ni un servidor web Apache. Es una aplicación Java de escritorio que se conecta directamente a https://pokeapi.co.

Esto se evidencia principalmente en los archivos PokeApiGUI.java y PokeApi.java.
